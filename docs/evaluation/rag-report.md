## Limitations

- The FastEmbed relevance threshold (0.68) was calibrated on this set: top-1 cosine similarity was 0.709-0.898 for answerable questions and 0.454-0.654 for unrelated ones (incl. 7 extra probes such as "Can I bring my dog?"). It is not validated on independent data.
- 28 questions written by the developer from the same documents: this is a development set, not an independent test set; results are optimistic.
- Keyword-based correctness does not judge fluency or partially correct answers.
- Latency is measured in-process on one machine and excludes network/HTTP and human waiting time.
- With the offline generator answers are extractive; rerun with `OPENAI_API_KEY` set to evaluate LLM generation.
